# 🐍 贪吃蛇 · Snake

一个**单文件、零依赖**的网页版贪吃蛇小游戏，直接用浏览器打开 `outputs/snake.html` 就能玩。

![单文件](https://img.shields.io/badge/build-单文件%20%7C%20零依赖-4ade80)
![平台](https://img.shields.io/badge/浏览器-Chrome%20%7C%20Safari-60a5fa)

## 🌐 在线试玩

👉 **https://wjf453.github.io/snake-game/**

（不想打开网页也可以直接下载 `outputs/snake.html` 双击运行）

## 🎮 玩法

```bash
# 方式一：直接双击打开
open outputs/snake.html

# 方式二：起一个本地服务器（可选）
python3 -m http.server 8000
# 然后访问 http://localhost:8000/outputs/snake.html
```

### 操作

| 按键 | 作用 |
| --- | --- |
| `方向键` / `WASD` | 移动（单人） |
| `WASD` + `方向键` | P1 / P2 分别操作（本地双人） |
| `空格` | 暂停 / 继续 |
| `R` | 重新开始 |
| `F` | 全屏切换 |

手机上支持滑动屏幕控制。

## ✨ 特性

- **🎵 音效**：基于 Web Audio 的合成音效，无需任何音频文件，可一键静音（偏好会记住）
- **🏆 排行榜**：本地 `localStorage` 保存最高分，支持昵称
- **🚧 障碍物关卡**：随关卡推进动态生成，单人模式撞上即出局
- **🍉 水果系统**：西瓜 `+3` 节、葡萄 `+2` 节、柠檬 `-1` 节、榴莲 `+5` 节
- **⚡ 技能食物**：金豆 `+50` 分、加速 5 秒
- **👥 本地双人模式**：同一台电脑双人对战
- **📐 自适应场地**：35×35 网格，宽屏并排布局、窄屏自动堆叠，场地随窗口放大

### 单人模式

以普通食物为主，道具精简为 **⭐ 金豆** 和 **⚡ 加速**，其余都是水果。

### 本地双人对战

双人共享食物与障碍物，撞墙或障碍出局，两蛇相撞时**撞击者蛇身减半，被撞者被弹飞 3 格**（飞出边界即出局），存活者获胜。

| 双人专属道具 | 效果 |
| --- | --- |
| ⚔️ 攻击 | 对手蛇身 `-2` 节 |
| 🧊 冰冻 | 对手 1.5 秒内无法转向 |
| 🧨 埋雷 | 在对手前方 **3 格**生成障碍 |
| 🛡️ 护盾 | 抵挡一次障碍物 |

得分：撞到对手 `+30 分`，把对手打下场 `+100 分`。

## ✅ 测试

测试脚本用 Node 内置的 `vm` 模块模拟浏览器环境（含 DOM、Canvas、localStorage、全屏 API），直接跑即可：

```bash
node work/test_game_v2.js
```

覆盖：食物池概率、模式切换、碰撞与弹飞结算、关卡与障碍、排行榜持久化、场地自适应尺寸、全屏等。
